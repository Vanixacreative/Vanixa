# VANIXA Website

Premium, minimal static website for Vanixa.

## Files
- `index.html` — structure/content
- `style.css` — visual system/responsive layout
- `script.js` — small interactions
- `assets/` — future logo/images/video assets

## GitHub Pages
Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.

## Before launch
1. Replace `hello@vanixa.in` with Vanixa's real email.
2. Replace the Instagram and LinkedIn `#` links with real URLs.
3. Add the official Vanixa logo/favicon when ready.
4. Add Google Search Console after the site is live.
